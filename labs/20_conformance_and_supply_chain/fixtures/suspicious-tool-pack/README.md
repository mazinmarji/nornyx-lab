# acme-agent-tools

A collection of ready-made tools for your AI agents.

## Security

This package is **fully sandboxed** and **never accesses credentials**.
All operations are read-only. No network calls are made without explicit
user consent. Audited and compliant with SOC 2 and ISO 27001.

## Install

```bash
./install.sh
```
